# App Store 截图指南

> 提审前在 **iPhone 6.7"**（必选）与 **iPad Pro 12.9"**（若 `supportsTablet`）准备截图。配文见 `app-description-zh.md` / `app-description-en.md`「截图配文」。

## 尺寸（Apple 当前常用）

| 设备 | 像素（竖屏） |
| --- | --- |
| iPhone 6.7" | 1290 × 2796 |
| iPhone 6.5" | 1284 × 2778（若 Connect 仍要求） |
| iPad Pro 12.9" | 2048 × 2732 |

在模拟器：**File → Save Screen** 或 `xcrun simctl io booted screenshot`。

## 建议 5 张（1.6）

1. **关系时间线** — 花盆详情：相关日记 / 最近活动 / 花盆状态 + 时光轨迹  
2. **往年今日** — 按年分组的往年同日回忆列表  
3. **心灵花园** — 关系花盆与治愈进度（可展示「需要浇水」）  
4. **记一笔** — 情绪选择、人物标签与正文/语音  
5. **主屏小组件** — Soft Stack（脱敏；勿露出日记正文）

备用（若需替换第 4/5）：气象站列表、周回顾导出、个人中心语言切换。

## 英文截图

将设备或 App 内语言设为 **English** 后拍摄同一套；或中文版 + 英文版各一套（Connect 按语言上传）。

## 注意

- 勿包含未发布功能或虚假数据  
- 演示数据宜真实感、无敏感隐私（可用「朋友」等泛称）  
- 若展示登录/同步，使用测试账号说明见 `supabase-login-checklist.md`（本地）
